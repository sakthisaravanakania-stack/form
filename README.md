A responsive Student Registration Form built using HTML, CSS, and JavaScript.

## 🚀 Features

- Student Registration Form
- First Name & Last Name
- Email Address
- Address
- Pincode
- State
- Country
- Gender Selection
- Form Validation
- Displays submitted data in a table
- Responsive Design for Desktop & Mobile
- JavaScript DOM Manipulation
- Dynamic Table Update
- Auto Form Reset after Submit

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM)

## 📱 Responsive Design

- Desktop
- Tablet
- Mobile Devices
